## Design Context

### Users
Privacy-conscious technical users (developers, indie hackers, infosec folks) who want a frictionless place to write and persist plain text without trusting the server. They open the app from a browser tab, often alongside terminals and code editors. The job to be done: capture and re-open private notes from any device using only a username + password — with cryptographic proof that nobody else (including the server operator) can read them.

### Brand Personality
Quiet. Trustworthy. Tool-like. Three words: **precise · calm · invisible**. The kind of tool people screenshot for "minimal setup" threads.

### Aesthetic Direction
Dark, ultra-minimal — premium developer-tool grade.
- **References**: Linear, Vercel, Raycast — restraint, geometric precision, generous negative space.
- **Anti-references**: glassmorphism, neon/glowing accents, gradient text, dashboard chrome, side-stripe borders, "secure messenger" green padlocks, decorative icons above headings.
- **Theme**: Dark only (no light mode). The product is used in long writing sessions; the dark surface is intentional, not aesthetic default.

### Palette (single source of truth)
- **Base**: `#080808`
- **Surface**: `white/[0.04]`
- **Border**: `white/[0.06]`
- **Text primary**: `white`
- **Text secondary**: `white/50`
- **Text tertiary**: `white/20`
- **Hairline / footer**: `white/[0.08]`
- **Accent (status only)**: emerald (saved), red (destructive). Always muted (~40–60%).

No other opacity values. No gradients. No tinted neutrals beyond the table above.

### Typography
- **UI**: Geist Sans — `tracking-[-0.04em]` on display, `tracking-[-0.02em]` on body, normal on micro-labels.
- **Editor**: Geist Mono — `14.5px / 1.85` line-height, max-width ~680px. The textarea *is* the product.
- **Scale**: 11, 12, 13, 14, 26 (and only those). Aim for ~1.25–1.4 ratio between adjacent steps.

### Design Principles
1. **Disappear into the writing.** The chrome should never compete with the textarea.
2. **If an icon communicates it, kill the label.** Lock is an icon. Save status is a 6px dot. Word count is just a number.
3. **State whispers, never shouts.** Save indicators, errors, migrations all sit at low opacity.
4. **One palette, no improvisation.** Every color/opacity/border value comes from the table above.
5. **Motion is feedback, not flourish.** 200ms ease-out transitions on color/opacity only. No bounces.
