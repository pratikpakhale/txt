## Design Context

### Users
Privacy-conscious technical users (developers, indie hackers, infosec folks) who want a frictionless place to write and persist plain text without trusting the server. They open the app from a browser tab, often alongside terminals and code editors. They expect speed, no signup ceremony, and a tool that gets out of the way.

The job to be done: capture and re-open private notes from any device using only a username + password — with cryptographic proof that nobody else (including the server operator) can read them.

### Brand Personality
- **Restrained.** No marketing copy, no labels for things an icon already communicates.
- **Trustworthy.** AES-256-GCM is mentioned once, quietly, at the bottom of the editor — not as a banner.
- **Premium.** The kind of tool people screenshot for "minimal setup" threads. Linear / Vercel / Raycast adjacency.

Three words: *quiet, precise, sharp-edged*.

### Aesthetic Direction
- **Dark only.** Background `#080808` (a tinted near-black, not pure `#000`). Text `#e8e8e8`.
- **Geist Sans** for UI, **Geist Mono** for the writing surface — already loaded by `next/font`.
- **No icon-above-heading templates, no card grids, no glow accents, no gradients.** A single-column login, a single full-bleed textarea. The interface is mostly *absent*.
- References: Linear's command bar, Vercel dashboard's empty states, Raycast's main window. Anti-references: Notion's chrome, "secure messenger" apps with green padlocks and bold green text.
- One color carries meaning beyond white-with-opacity: a 6px emerald dot for "saved" — easy to miss, which is the point.

### Design Principles
1. **If an icon communicates it, kill the text label.** The lock button is just an icon. The save status is a 6px dot. The word count is just a number — no "words" suffix.
2. **Opacity is the only scale.** Hierarchy comes from `text-white/70`, `/30`, `/20`, `/08` — not from extra weights or sizes piled on.
3. **Generous breathing room.** `max-w-[320px]` for the login, `max-w-[680px]` for the editor, `leading-[1.85]` for body text. Cramped is the failure mode to avoid.
4. **One accent rule.** Color is white-on-dark. Red appears only where destruction does. Emerald appears only when saved. Nothing else gets a hue.
5. **No half-built UI.** No "New user? Just enter…" hint paragraphs, no redundant headers, no labels above inputs that already have placeholders.
